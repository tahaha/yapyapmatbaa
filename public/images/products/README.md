# Bu klasör ürün görsellerini içerir.
# Görsel dosyalarınızı buraya ekleyin.
#
# Önerilen format: WebP (daha küçük dosya boyutu)
# Önerilen isim formatı: urun-slug.webp veya urun-slug-varyant.webp
#
# Örnekler:
#   kartvizit.webp
#   brosur.webp
#   magnet.webp
#   cikartma-etiket.webp
#   el-ilani.webp
#   afis.webp
#
# Görseli ekledikten sonra src/data/products.js içindeki
# ilgili ürünün "image" alanını güncelleyin:
#   image: 'images/products/kartvizit.webp'
#
# Veya admin panelinden Ürün → Düzenle → Ürün görseli yolu alanını güncelleyin.
